This project focuses on feature engineering (FE) and exploratory data analysis (EDA)
for credit risk modeling using cumulative payment-to-bill ratios over a
6-month period. EDA is focused on behavioral instability rather than static ratios.

Models will be trained on the processed data in future work.

Dataset:
https://www.kaggle.com/datasets/uciml/default-of-credit-card-clients-dataset
